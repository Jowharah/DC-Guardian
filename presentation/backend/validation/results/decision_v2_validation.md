# DCG-DECISION-v2 group rule — selection and validation

Generated by `presentation/backend/validation/decision_v2_validation.py`. Groups are formed as in the live system (crisp-correlated abnormal events, 2+). A group is **genuine** when all its events belong to one labelled incident. Labels were written by the scenario author; the scenarios have no severity labels, so this tests whether escalation picks out real incidents, not whether each level is right.

## Caveats

- Author labels: the rule was designed and tested against labels written by the same author, and the known-mechanism list mirrors the scenario design. Independent labels (the blind labelling pack) are needed before stronger claims.
- Small sample: few test groups, so the interval is wide.
- Single-event severities are an operator-approved policy and are not validated by these labels.
